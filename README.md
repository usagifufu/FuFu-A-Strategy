# FUFU 大A操作体系（FuFu-A-Strategy）

> **Fufu（芙芙）炒股实战体系** —— AI 半自主交易员方法论与完整操作框架
>
> 面向 A股 / 港股通 / ETF 的五大体系融合框架，含快评与深度研究双模式。

---

## 📊 五大体系

| 体系 | 核心能力 |
|------|---------|
| 🐺 **Fufu 炒股·趋势波浪体系** | 波浪理论、趋势判定、仓位管理、主线识别 |
| 📐 **Fufu 炒股·量化风偏体系** | 波动率、拥挤度、分子端/分母端逻辑、风偏检查 |
| 📊 **Fufu 炒股·突破选股体系** | 第二阶段（Stage 2）、VCP 波动收缩、突破买点 |
| ☁️ **Fufu 炒股·深度评级体系** | 六维并行研究、三情景概率加权、F红线、先例库 |
| 📏 **Fufu 炒股·均线纪律体系** | 5/20 日均线分水岭、破线止损、盈亏比思维 |

---

## 🎯 双模式输出

- **快评模式（默认）**：盘中快节奏研判，多周期多风格分析简报（暗色 HTML）
- **深度研究模式**：六维并行 + 三情景概率加权裁定 + 空仓视角操作框架（完整评级报告）

## 📐 操作纪律（铁律）

1. **-5% 无条件止损**（FuFu 铁律）
2. **单票仓位 ≤ 20%**
3. **20 日线上方顺势 / 跌破绝不加仓**
4. **红涨绿跌**（中国习惯配色）
5. 决策 = 快评捕捉机会 → 深度评级验证价值 → 先例库沉淀纪律
